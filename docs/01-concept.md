# 01. Концепция

## Что это

**agent-compositor** — открытый рантайм для CLI-агентов LLM по аналогии с композитором Wayland. Терминал — это дисплей, агентное ядро — это кернел, плагины — клиенты. Протокол между ними версионируется и стабилен, реализации сменяются.

| Wayland | agent-compositor |
|---|---|
| DRM / кернел | Ядро: agent harness (модели, инструменты, сессии, компакшн контекста) |
| `wl_protocol` (версионированный) | Каталог событий + wire-протокол «ядро ↔ рендерер» (semver) |
| Клиенты | Плагины |
| Weston / Sway (сменный композитор) | Рендереры: TUI (Ink), headless, web |
| Поверхность (`wl_surface`) | Pane — именованный буфер ячеек |
| Ввод и фокус (seat) | Маршрутизация ввода между панелями |
| Damage tracking | Инкрементальная перерисовка (`invalidate`) |

## Три слоя

1. **Ядро (core)** — неприкосновенный «стек драйверов». Событийная шина: каждый вызов API проходит через цепочку обработчиков (onion-модель: событие → матчеры → обработчики → команды → ядро → обратно).
2. **Capability-плагины** — модели, SSO/login, workflow-движки, инструменты. Меняют поведение ядра.
3. **Render-only** — всё, что рисует, но не меняет состояние агента: темы, раскладки, визуализации.

## Принципы

1. **Всё — событие.** Любое расширение оформляется как обработчик события, а не как патч ядра.
2. **Контракт стабилен, реализации меняются.** Как syscall ABI у Linux: каталог событий версионируется, legacy-имена живут как алиасы.
3. **Провайдер — плагин, а не форк.** Минимальный дистрибутив: перегрузить вход на свой SSO и добавить плагин модели.
4. **Не запирать чужие технологии.** Механики, хорошо работающие у одного вендора (hooks, plugins, workflows), становятся нативными для всех.
5. **Рендерер — расходник.** Женимся на модели компонентов, а не на конкретном движке; движок можно заменить, не трогая компоненты.

## Откуда растёт

Ядро выращено из форка [kimi-code](https://github.com/Neko1313/kimi-code) (ветка `feat/plugin-in-process-runtime-poc`): in-process плагин-рантайм с onion-цепочкой событий, `HookScope`-бюджетами (часы останавливаются, пока обработчик ждёт `next()`), fail-operational каскадом (ошибка/таймаут не роняют сессию) и совместимостью с Claude Mods API. Рантайм прошёл внешнее архитектурное ревью; открытые пункты перечислены в [03-contracts.md](03-contracts.md).
