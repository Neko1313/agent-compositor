# Runner fixture

`vitest.json` was produced by a real Vitest 5.1.0 run with the JSON reporter:
one passing assertion, one deliberately failing assertion and one skipped case.
The producing test asserted `2 + 2 === 4`, `2 + 2 === 5` and a skipped case.
Machine-specific sample-directory paths were replaced with `fixture/`; the
runner's JSON shape, statuses and diagnostics are retained. This is test data,
never instructions or executable code. Additional controlled malformed and
bounded-input cases are generated by the package contract.
